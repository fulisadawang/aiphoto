# AI选片

摄影师自用的 Mac 选片客户端，面向亲子 / 家庭纪实拍摄。

## 编译运行

需要 Xcode 与 [XcodeGen](https://github.com/yonaskolb/XcodeGen)（`brew install xcodegen`）。

```bash
xcodegen generate
xcodebuild -project AIPhoto.xcodeproj -scheme AIPhoto -configuration Release -derivedDataPath build/DerivedData build
open build/DerivedData/Build/Products/Release/AIPhoto.app
```

`AIPhoto.xcodeproj` 由 `project.yml` 生成，改工程配置请改 `project.yml`。

## 使用流程

1. 打开一场拍摄的文件夹（⌘O，或把文件夹拖到窗口 / Dock 图标上）。RAW 与同名 JPG 自动配对。
2. 自动本地分析：主体清晰度、人脸与闭眼、曝光，按连拍分组，每组预选一张。
3. 「AI 选片」（⌘R）：每组本地评分最高的几张发给看图模型，按亲子纪实标准择优并写出理由、问题和可去除的干扰物。默认走本机 Magpie（`http://127.0.0.1:3425/v1`，模型 `group/auto-auto`），可在「AI选片 › 设置… › AI 选片模型」修改；任何 OpenAI 兼容的 `/chat/completions` 看图接口都可以。
4. 浏览确认：← → 切换照片，↑ ↓ 切换组，P 选用，X 淘汰，U 取消，1-5 打星，空格放大到人脸，F 显示人脸框。
5. 修图（可选）：右侧「修图」里点「自动」（A）做白平衡、曝光、高光阴影；可手动微调，「\」对比原图。「皮肤柔化」只处理人脸皮肤，五官保持清晰。「风格」套用从你的样片学到的调色（见下文）。「同步到本组」把当前参数套用到整组，「选片 › 已选照片自动调色」批量处理。
6. 去杂物（可选）：按 B 进入画笔模式，在大图上涂抹要去掉的物体（[ ] 调画笔大小），回车消除，Esc 清除涂抹；「撤销上一次」可回退。需先在设置里配置「去杂物服务」。
7. 导出：「选片 › 把选片结果写入 RAW 的 XMP 星级」（⇧⌘E）、「拷贝已选照片到文件夹」，或「导出已选成片（JPG）」（⌘E，RAW 会完整解码后套用调色）。

## 数据存放

- 选片进度：照片文件夹内的 `.aiphoto/session.json`，重新打开时直接恢复。
- XMP：写在 RAW 旁边的同名 `.xmp`；已有 XMP（如 Lightroom 修图参数）时只改 `xmp:Rating`。选用默认 3 星，淘汰写 -1（拒绝）。
- 只有 JPG 的照片不写 XMP，请用拷贝导出。

## 已知限制

- 闭眼判断看眼部区域深色像素的高度（Vision 的眼部关键点几乎不随眼皮开合变化，不可靠）。大笑眯眼也可能被标记，仅作提示，最终以 AI 和人工判断为准；目前只在少量生成照片上验证过。
- 主体清晰度：人脸 > 人体框 > 同组照片的人体框 > 画面最清晰区块。Apple 的人脸/人体检测对戴帽子的背影、小侧脸经常认不出，同一组连拍会借用组里认出来的人体位置，保证组内按同一区域比较；表情和"有没有拍到脸"交给 AI 选片判断。
- 模糊的绝对阈值只用于人脸区域，无人脸画面只在组内相对比较。阈值可在设置里调整。
- 竖拍照片按相机方向标记自动转正，RAW（已实测佳能 R6 Mark II 的 CR3）完整解码后导出。
- 有 RAW 的照片：浏览用相机 JPG（快）；一旦调色或去杂物，预览改用 RAW 解码，与导出成片一致。自动调色和风格学习也基于 RAW 解码，所以 RAW 照片调色后会比相机 JPG 观感略平，这是正常的中性起点。
- 自动白平衡只校正 70%，保留室内暖光氛围；曝光自动补偿上限 ±1.5 EV。
- 调色参数只作用于预览和导出成片，不写入 XMP，Lightroom 里看不到。去杂物同理。

## 个人风格

「选片 › 从修图样片学习风格…」：先选原图文件夹，再选修好的成片文件夹（如像素蛋糕导出的 JPG，文件名与原图相同）。程序逐像素对比，学出一张 3D 色彩查找表（17³ LUT），存在 `~/Library/Application Support/AIPhoto/styles/`，所有文件夹共用。

- 只学整体调色（色温、色调曲线、饱和度等），不学局部修饰（磨皮、液化、去瑕疵）。
- 成片被裁切过（宽高比不同）的样片对会被跳过。
- 样片建议 20 对以上，并覆盖室内、室外、逆光等不同光线。

## 去杂物服务配置

设置 › 去杂物服务 › 选「OpenAI 兼容接口」，调用 `<接口地址>/images/edits`。

- 默认即本机 Magpie：接口地址 `http://127.0.0.1:3425/v1`，不需要密钥，**模型留空**（Magpie 会用默认图片模型 `codex/gpt-image-2`）。填 `group/auto-auto` 这类对话模型会只返回文字、不出图。
- 只上传涂抹区域附近的正方形局部图（最长边 1024），结果先按区域外颜色校正，再羽化贴回；区域外像素始终是原图。
- 修补结果保存在照片文件夹的 `.aiphoto/patches/`，删除该目录会导致已消除的照片报"修补文件丢失"。
