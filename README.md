# AI选片

给亲子 / 家庭纪实摄影师用的 Mac 原生选片客户端。拍完一场几百张 RAW+JPG，用它快速分组、挑片、做第一遍修复（调色、去路人杂物），选中的照片再交给 Lightroom、像素蛋糕等软件精修。

SwiftUI + Core Image + Vision 实现，AI 部分调用任何 OpenAI 兼容接口（看图对话 `/chat/completions`、改图 `/images/edits`）。

## 功能

- **本地分析与分组**：主体清晰度、人脸与闭眼、曝光；按连拍和同场景自动分组，每组预选一张。
- **AI 选片**：每组把本地评分最高的几张发给看图模型，按亲子纪实标准择优（哭、闭眼大笑不算废片，互动优先），写出理由、问题和可去除的干扰物。
- **看片辅助**：滚轮 / 双击 / Z 键放大，空格放大到人脸，导航小图；合焦高亮（K）、过曝提示（J）、直方图与拍摄参数、佳能相机对焦点（F）。
- **修复前后对比**：按 `\` 出现分割线，左原图右修复后，放大平移时两侧同步。
- **初修**：自动白平衡和曝光（带高光保护）、皮肤轻度柔化、个人风格 LUT；画笔涂抹去杂物，或让 AI 找出路人推车等干扰物一键去除；「一键初修」对所有已选照片全自动处理并给出每张的总结。
- **对话改图**：右侧面板用一句话修改当前照片（"亮一点""把右边的路人去掉""帮她去一下黑眼圈"），可以多轮接着调。
- **网格总览**（G）：按组铺开整场照片，框选后批量选用 / 淘汰。
- **撤销 / 重做**（⌘Z / ⇧⌘Z），覆盖选片标记、修图参数和去杂物。
- **导出**：选片结果写入 RAW 旁的 XMP 星级（Lightroom 可读），拷贝已选原片，或导出套用修复后的 JPG。

## 环境要求

- macOS 15 及以上；作者用 Xcode 27.1 编译
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)：`brew install xcodegen`
- 一个 OpenAI 兼容的模型服务（AI 选片、去杂物、对话改图需要；只用本地分组和手动选片可以不配）

## 编译运行

```bash
xcodegen generate
xcodebuild -project AIPhoto.xcodeproj -scheme AIPhoto -configuration Release -derivedDataPath build/DerivedData build
open build/DerivedData/Build/Products/Release/AIPhoto.app
```

`AIPhoto.xcodeproj` 由 `project.yml` 生成，改工程配置请改 `project.yml`。工程使用本机临时签名、不开沙盒，只适合自己编译使用。

## 模型服务配置

在「AI选片 › 设置…」里配置，默认值指向作者本机运行的 Magpie 模型网关（`http://127.0.0.1:3425/v1`，不需要密钥）：

| 用途 | 接口 | 默认模型 | 说明 |
|---|---|---|---|
| AI 选片 | `/chat/completions` | `group/auto-auto` | 需要能看图 |
| 对话改图 | `/chat/completions` | `group/auto-gemini-3-8-flash` | 需要能准确框出物体位置，实测 Gemini 系列更准 |
| 去杂物 / 重画 | `/images/edits` | 留空（服务默认图片模型） | 必须是能出图的模型 |

换成其他服务时，把接口地址和模型改成该服务提供的即可；需要密钥的服务在设置里保存到钥匙串。

**隐私**：AI 选片会上传缩小后的照片，去杂物和对话改图会上传照片的局部或缩小图到你配置的服务。用本机服务时照片不出电脑；用云端服务前请确认对方的数据政策。

## 使用流程

1. 打开一场拍摄的文件夹（⌘O，或把文件夹拖到窗口 / Dock 图标上）。RAW 与同名 JPG 自动配对。
2. 自动本地分析并分组，每组预选一张。
3. 「AI 选片」（⌘R）评估每组并推荐。
4. 浏览确认：← → 切换照片，↑ ↓ 切换组，P 选用，X 淘汰，U 取消，1-5 打星，G 网格总览。
5. 初修：「选片 › 一键初修已选照片」（⇧⌘R）全自动处理；或在右侧面板逐张调色、去杂物、对话改图。按 `\` 对比修复前后。
6. 导出：「选片 › 把选片结果写入 RAW 的 XMP 星级」（⇧⌘E）、「拷贝已选照片到文件夹」，或「导出已选成片（JPG）」（⌘E）。

## 数据存放

- 选片进度、修图参数、对话记录：照片文件夹内的 `.aiphoto/session.json`，重新打开时直接恢复。
- 去杂物修补块：`.aiphoto/patches/`，删除该目录会导致已消除的照片报"修补文件丢失"。
- 个人风格：`~/Library/Application Support/AIPhoto/styles/`，所有文件夹共用。
- XMP：写在 RAW 旁边的同名 `.xmp`；已有 XMP（如 Lightroom 修图参数）时只改 `xmp:Rating`。只有 JPG 的照片不写 XMP。
- 原片始终只读。

## 已知限制

- 闭眼判断看眼部深色像素的高度（Vision 的眼部关键点几乎不随眼皮开合变化）。大笑眯眼也可能被标记，仅作提示。
- Apple 的人脸 / 人体检测对戴帽子的背影、小侧脸经常认不出，同一组连拍会借用组里认出来的人体位置来比较清晰度。
- 修图底图优先用相机 JPG（保留相机色彩），只有 RAW 时才解码 RAW。调色参数和去杂物只作用于预览和导出成片，不写入 XMP。
- 去杂物只上传涂抹区域附近的局部图（最长边 1024），结果按区域外颜色校正后羽化贴回；大面积重画会变糊，对话改图会拒绝放大超过 3 倍的重画。
- 主要在佳能 R6 Mark II 的 CR3+JPG 上测试；相机对焦点目前只支持佳能。

## 个人风格

「选片 › 从修图样片学习风格…」：先选原图文件夹，再选修好的成片文件夹（文件名与原图相同）。程序逐像素对比，学出一张 17³ 的 3D 色彩查找表。

- 只学整体调色，不学局部修饰（磨皮、液化、去瑕疵）。
- 成片被裁切过（宽高比不同）的样片对会被跳过。
- 样片建议 20 对以上，并覆盖室内、室外、逆光等不同光线。
